First time? 4-step setup guide (≈4 min)
  1. Go to supabase.com → sign in → New project (free). Pick any name + password, wait ~1 min for it to build.
  2. Left sidebar → SQL Editor → New query → paste this and click Run: 
    create table if not exists tracker (
  id text primary key,
  data jsonb,
  updated_at timestamptz default now()
);
alter table tracker enable row level security;
create policy "team access" on tracker
  for all using (true) with check (true);
alter publication supabase_realtime add table tracker;
  3. Left sidebar → Project Settings → API. Copy the Project URL and the anon public key.
  4. Paste both above → Connect. Then click Copy invite link in the header and send it to the team — they connect in one click. Pwedeng i-bookmark.
