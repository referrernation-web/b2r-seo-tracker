# Workspace extension

## Direction contract
THESIS: A task-first workspace. Replace the all-fields-at-once working table with
a compact list and explicit detail editing; retain all fields and the reporting/help screens.

OWN-WORLD: Inherit the tracker paper, forest, ink palette and Spline Sans.
Use fine separators and calm controls, without adding illustrations or decorative cards.

STORY: Choose a client and saved view, find a task, open its details, save a deliberate
change, and receive accurate persistence feedback. The existing login stays unchanged.

FIRST VIEWPORT: Compact workspace header, existing client navigation, task navigation,
saved-view chips, one search/filter row, one Add task action, and six scan-friendly columns.
Side panel holds the full record. Mobile uses stacked rows and a full-screen detail panel.

FORM: User-approved task table and side panel; extension of the existing visual world.
No concept roll or generated imagery needed for this explicitly selected interaction pattern.
Signature interaction: open and close a detail panel without losing filter or list position.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
